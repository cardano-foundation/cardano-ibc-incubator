Packet settlement uses at most five authenticated escrow deposits. If total available backing covers a return or refund but the five largest deposits do not, the Gateway builds a consolidation of those five deposits. Hermes authorizes it against the original packet, waits for confirmed inclusion and asks the Gateway to rebuild that same settlement. A genuine backing shortfall does not trigger consolidation. Inputs reserved by another in-flight transaction are excluded from both selection and consolidation.

Consolidation keeps all principal and the surviving deposit's reserve in escrow. It reimburses each removed deposit's reserve owner. The relayer pays the transaction fee from its own wallet under its configured signing limits. Hermes permits at most eight consolidation transactions per request before asking the caller to resume. Already confirmed consolidations remain useful to that retry. Consolidation alone does not report the packet as settled.
